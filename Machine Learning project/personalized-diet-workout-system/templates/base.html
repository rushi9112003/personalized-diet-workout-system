Machine Learning System Overview
Content-Based NearestNeighbors Recommendation

This system uses a content-based recommendation approach powered by scikit-learn.neighbors.NearestNeighbors with Cosine Distance metric on preprocessed and scaled feature vectors.

Algorithm & Pipeline Breakdown:
  • Constraint Filtering: Hard filters for Dietary Preference (Veg/Vegan/Eggetarian/Non-veg) and zero-tolerance Food Allergy exclusion.
  • Feature Encoding: Nutrition vector [Calories, Protein, Carbs, Fat, Fiber] for foods, and [Intensity, Calorie Burn] for workouts.
  • StandardScaler: Standardizes features (\(\mu=0, \sigma=1\)) preventing high-magnitude features (e.g. calories) from dominating distance metrics.
  • Cosine Distance Metric: \(D_C(\mathbf{u}, \mathbf{v}) = 1 - \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}\). Focuses on optimal macronutrient ratio alignment.
  • Rule-Based Portion & Split Engine: Portion multiplier (0.7x–1.4x) and weekly split scheduling (3 to 6 days) combined with ML rankings.
Educational Project Note: Built with local CSV datasets (Indian and accessible foods). No medical advice implied.
